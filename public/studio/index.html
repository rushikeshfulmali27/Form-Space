RULES-BASED EDITOR

Small prompts.
Visible changes.

This editor matches local rules for supported properties. It updates parametric catalog objects; it does not generate arbitrary new 3D models.

  • Color: “Make it sage green with black legs”
  • Size: “90 cm wide and 80 cm tall”
  • Relative: “20% taller”, “reduce height by 20%”, or “make it smaller”
  • Material: “Use walnut” or “brushed metal”
  • Shape: “Make the top round” on supported objects
  • Shelves: “Add 5 shelves” on a rack or bookshelf
  • Object: “Switch to the floor lamp”

Size units: cm (default), mm, m, inches, feet. Three values use Width × Depth × Height. Export a design to keep a portable copy. Workspace edits are saved in this browser when storage is available. Wood grain and metal shading are procedural approximations; this is a visual demo, not a CAD or manufacturing tool.
